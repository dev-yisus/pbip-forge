# Security Policy

## Supported Versions

We actively support and provide security patches for the following versions of **pbip-forge**:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

The **pbip-forge** project takes security seriously. If you discover a security vulnerability, please report it privately:

1. **Do not create a public issue** on GitHub.
2. Open a private security advisory through the [GitHub Security Advisory](https://github.com/dev-yisus/pbip-forge/security/advisories/new) dashboard, or email `dev-yisus@users.noreply.github.com`.
3. Provide detailed steps to reproduce the vulnerability.

We will acknowledge receipt within 48 hours and work on a mitigation or fix promptly.
